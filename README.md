## ♿ Responsive playbook

- **Fluid type with `clamp()`** — headings and body text scale continuously from 320px to 5120px.
- **No fixed pixel widths** — grids use `minmax(0, 1fr)` and `flex-wrap`, so zero horizontal scroll.
- **`object-fit: contain` on screenshots** — project images keep their natural aspect ratio, never cropped.
- **Thumb-first navigation** — 44px tap targets and a collapsible drawer below 1024px.
- **Tables that collapse** — device matrices become stacked cards on small screens.
- **Accessible by default** — `prefers-reduced-motion`, semantic landmarks, alt text, AA contrast.
